适用范围：用户确实要检索、筛选或推荐具体课程时才执行本Skill。问候、介绍、感谢、一般闲聊和知识／方法讨论直接自然回答，不要求先提供选课条件，不修改已有候选和筛选。宽泛推荐可查询现有目录，不强制追问。
查询 Skill：保留会话中未被用户修改的条件，显式新要求优先。
1. 判断课程、教师或兴趣主题是否明确；“评分”口径不明时追问 GPA 还是教师评分。
2. 调用 search_courses。明确查询某门课程或教师时 semantic=false，按兴趣主题寻找课程时 semantic=true。filters_patch 只写本轮明确修改的字段；null 表示清除该字段。没有关键词时 query=""。
3. 对拟推荐课程调用 get_course_evidence，核对数值与教师评价归属。
4. 零结果不放宽硬条件；歧义先列候选或追问。
5. 使用工具返回的ID组织回答。历史数据不能证明本期开课、余量、学分或个人最终成绩。
