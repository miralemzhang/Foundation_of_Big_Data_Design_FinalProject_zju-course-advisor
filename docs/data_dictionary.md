# 数据与字段口径

以下规模描述另交老师的完整历史数据；公开仓库默认是虚构结构样例，规模见data/README.md。

数据版本及输入SHA256见 `data/manifests/catalog.json`，运行 `scripts/audit_data.py` 核对输入未改变。

| 数据 | 当前口径 |
|---|---|
| gpa.json | 6,442个教师姓名键、17,479条教师—课程记录、5,288个不同原始课程名称字符串 |
| teachers.csv | 10,043个教师ID；原始姓名字符串9,544种；去首尾空白后9,542种；规范化后9,537种。不能把姓名数当人数 |
| comment_*.csv | 131个文件，去表头216,646行；姓名及内容非空216,351行；不是独立评课人数 |
| courses_selected.txt | 674条历史带标签记录；10条课程名内部的标签括号经去括号后与GPA原名精确对应；1条“心理健康／胡少华”不能精确关联，保留在未解决记录中 |
| 当前候选 | 673条课程—教师记录、225个规范化课程名称、470个可唯一关联的教师ID |
| 当前关联评论 | 29,884条按教师ID去重关联的文本评论；其余原始评论在非公开材料中保留 |

88条候选记录存在同名教师歧义，27条未找到唯一教师表记录；这些候选保留课程GPA，但不强行附加教师评分和评论。另1条标签—GPA关联失败。合计116条未解决记录，详见 `data/processed/unresolved.jsonl`。

## 字段

- `offering_id`：根据原始教师名和完整GPA行生成的稳定本地ID；是历史统计记录，不是当期开课班次编号。
- `course_id`：按规范化课程名生成的本地ID；没有官方课程代码，不声称完成官方课程实体认证。
- `teacher_id`：来自教师CSV。GPA只有姓名时必须唯一匹配后才能挂接。
- `avg_gpa`：原始历史GPA，合法范围0–5；不能用来保证个人成绩。
- `student_count`：GPA原始人数文本，前端称“GPA来源人数”。不等同教师评分人数、文本评论数或实时选课人数。
- `gpa_count_lower` / `gpa_count_exact`：截断人数的保守下界及精确标志。`500+`保留原文，不足以确认满足至少1000人。
- `std_dev`：原始GPA标准差，不是模型预测误差。
- `teacher_rating` / `teacher_rating_count`：教师评分（0–10）及评分人数；无人评分时评分按缺失处理。
- `comment_count`：按已确认教师ID关联的去重文本评论数。
- `categories`：现有历史标签，可一条记录多标签，不等同当期官方类别认证。
- `college`：教师所在学院，不自动等同课程开课学院。
- `similarity`：课程名与类别的jieba分词、TF-IDF余弦相似度。不是教学质量、概率或实验证明的主题等价性。
- `data_version`：原始输入指纹及转换脚本指纹共同决定。修改处理规则后须重建数据库。

## 证据与云端知识库

本地统计保留JSON键／行号；教师和评论保留CSV逻辑行号及原始ID。教师评论仅作为教师级个人观点。

运行时复用 `ai practice` 中的历史 `rag_final_knowledge`，通过检索接口取得真实切片。切片可能串联多条历史评论，因此只有能与对应教师本地原文逐字匹配的片段才进入该教师的回答证据，且只传入匹配片段。云端下载签名URL不写入日志或响应。

`scripts/build_knowledge.py` 导出当前本地候选及来源到 `data/knowledge/`；导出不等同上传，`export_manifest.json` 明确记录 `uploaded=false`。更新本地原始数据后先重建目录，再导出；如需更新云端须另行完成导入和验证，现有云端数据不会被脚本自动覆盖。
