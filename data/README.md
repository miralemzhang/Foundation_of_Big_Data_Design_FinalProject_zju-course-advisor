# 数据使用与文件格式

`sample/`为虚构结构样例，不包含真实评价。完整历史数据另交老师，不在公开仓库中。

## 输入

构建脚本读取 `DATA_SOURCE_DIR`（默认 `data/sample`）：

| 文件 | 格式 |
|---|---|
| `gpa.json` | 教师姓名键映射至 `[课程名, GPA, 人数文本, 标准差]` 行数组 |
| `teachers.csv` | id、姓名、学院、热度、评分人数、评分、拼音、拼音缩写 |
| `courses_selected.txt` | 每行含 `课程名称：《…》，授课教师：…。平均绩点为…。` 和 `【类别】` |
| `comment_*.csv` | 评论id、老师id、老师姓名、发表时间、点赞减去点踩数量、点赞量、点踩量、内容 |

CSV为UTF-8，可带BOM；人数可为500+。类别从既有标签读取。同名教师不强行唯一关联。完整数据包应保留原文件名和输入内容，放在 `data/private/` 后配置 `.env`。也可用 `build_catalog.py --source-dir data/private` 单次构建，但随后审计和知识导出仍需将 `.env` 的数据源设置为相同目录。

## 输出与隔离

生成物 `data/processed/`、`data/manifests/`、`data/knowledge/` 均忽略提交。目录数据库与用户状态数据库分开，用户状态在 `runtime/`。切换数据后重建并重启服务；各次目录的版本由输入及构建脚本指纹共同决定。

虚构样例含17条记录、16个不同课程名称、15名唯一关联教师、15条构造评论，另含1条教师重名记录和1条未关联教师记录。不得将这些数字与完整实验数据规模混用。
